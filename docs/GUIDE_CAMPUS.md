# Kapsi Campus — Guide de démarrage

## Pour qui
Établissements d'enseignement engagés en ISO 21001. Construit à partir du processus Services généraux (GSG) de l'ISI : ses formulaires, plannings, registres et les 8 indicateurs de sa fiche processus.

## Démarrer en 5 étapes
1. **Clients → Nouveau client** : créez l'établissement (ou utilisez « Université Privée NovaTech (démo) »).
2. **Campus → Équipements** : déclarez les laboratoires, copieurs, bâtiments et véhicules (les fiches de vie suivent).
3. **Campus → Processus ISO 21001** : fixez les cibles des indicateurs avec les pilotes.
4. **Campus → Guichet numérique** : imprimez le QR code et le code d'accès, affichez-les dans les salles et les bureaux.
5. **Campus → Agents → Pilote Campus** : chaque lundi, il relance les retards, planifie la maintenance, suit les réclamations, calcule les indicateurs et ouvre les actions.

## Ce que fait chaque geste
- **Demander** (guichet) → une demande avec son formulaire de référence (GSG-FR-xx), son échéance et un ticket.
- **Exécuter** (Campus → Demandes, Plannings) → statuts, cases cochées, interventions enregistrées dans la fiche de vie.
- **Recevoir** (guichet, ticket) → le demandeur confirme et donne son avis : c'est la preuve des indicateurs GSG-3 et GSG-4.

## Indicateurs calculés automatiquement (fiche GSG-PP)
| Code | Indicateur | Données utilisées |
|---|---|---|
| GSG-1 | Planification du nettoyage | Planning de nettoyage coché |
| GSG-2 | Planification du gardiennage | Planning de gardiennage coché |
| GSG-3 | Demandes de moyens logistiques satisfaites | Demandes clôturées et avis de réception |
| GSG-4 | Tirages dans les délais | Date de réalisation ≤ échéance, avis favorable |
| GSG-5 | Conformité de l'archive | Inventaires (éléments, non-conformités) |
| GSG-6 | Réclamations traitées efficacement | Clôture dans les 7 jours, avis favorable |
| GSG-7a | Maintenance préventive informatique | Planning GSG-PL-05 coché |
| GSG-7b | Efficacité des interventions curatives SI | Fiches de vie, case « efficace » |

## Limites
- Les documents produits par les agents sont « À valider » par le pilote ou le RSMOE.
- Les indicateurs des autres processus sont proposés : leurs pilotes les valident et les saisissent.
- Le certificat ISO 21001 est délivré uniquement par un organisme accrédité.
- Le guichet est protégé par un code d'établissement, pas par un compte individuel : changez le code s'il circule hors de l'établissement.
